# Changelog

## 1.0.0
First public release.
- Always-on-top overlay window with global hotkey (default Ctrl+Alt+R), adjustable opacity, remembered position and size
- Recipe finder with ingredient grid and icons, "cook now" / "one ingredient missing" views, automatic "Any …" groups
- Healing, buffs and removed status effects for dishes and ingredients (hover or pinned card)
- English (default) and Italian interface; editable item names; translation assistant
- Recipe data refreshed weekly from sulfur.wiki.gg by GitHub Actions and downloaded automatically
- Automatic app updates through GitHub Releases
