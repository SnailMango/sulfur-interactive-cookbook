## SULFUR Interactive Cookbook v1.0.0 — first release 🎉

An overlay for **SULFUR** that puts recipes, ingredients, healing and buffs one hotkey away, on top of the game.

### Highlights
- 🍳 Pick your ingredients and see what you can cook now, or what is one ingredient away
- ❤️ Healing, buffs and removed status effects for every dish and ingredient
- 🪟 Frameless always-on-top overlay · **Ctrl + Alt + R** to show/hide · adjustable opacity
- 🌍 English (default) and Italian — switch with **EN | IT**
- 🔄 Recipe data and the app update themselves

### Install
Download **`SULFUR-Interactive-Cookbook-Setup-1.0.0.exe`** below and run it.
Windows may say *"Windows protected your PC"* (the app is not code-signed): click **More info → Run anyway**.

> ⚠️ Set SULFUR to **Fullscreen Window / Borderless** — overlays cannot appear over Exclusive Fullscreen.

*Unofficial fan project, not affiliated with Perfect Random. Recipe data from https://sulfur.wiki.gg.*
